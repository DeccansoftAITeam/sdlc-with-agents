## Decisions
- Ticket URLs use the per-tenant number (`/tickets/7`), not the UUID
- A ticket the caller may not see is 404, never 403 (don't reveal existence)
- Same-state status change is an illegal transition (409)
- Staff routes re-check the caller's role in the DB (same as PR B), so a deactivated user's 15-min token can't act
- The ticket's first body is stored as the first public message (no separate body column)
- Queue order: created_at desc, number desc (number breaks ties deterministically); cursor = (created_at, number)
- Test-only fast Argon2 profile (session fixture); production cost unchanged
